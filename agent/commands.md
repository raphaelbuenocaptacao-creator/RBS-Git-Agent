# Comandos do RBS Git Agent

Exemplos de linguagem natural que a interface pode traduzir para tarefas seguras:

- `Audite todos os meus repositórios.`
- `Compare o CaptaPro com o Analytics.`
- `Encontre código duplicado.`
- `Procure secrets expostos.`
- `Veja por que este dashboard está lento.`
- `Crie um plano para corrigir os problemas críticos.`
- `Implemente a correção em uma branch e abra um PR.`
- `Ensine ao agente que esta regra deve ser usada no futuro.`
- `Mostre tudo que mudou desde a última auditoria.`

Toda ação passa por política de risco. Comandos destrutivos nunca são inferidos a partir de linguagem ambígua.
